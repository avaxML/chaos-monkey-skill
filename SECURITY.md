# Security

This repository contains Markdown instructions for AI coding agents and a
small CI check. It ships no executable code to end users.

If you find a way this skill could cause an agent to take a destructive or
unauthorized action (for example, an instruction that leads to cloud mutation,
credential exposure, or force-pushes), please open a private report via
GitHub's "Report a vulnerability" button on this repository rather than a
public issue. Expect an acknowledgement within 7 days.
